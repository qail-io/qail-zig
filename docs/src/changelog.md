# Changelog

QAIL Zig now tracks its own release notes separately from qail.rs.

## Current Highlights (`v0.6.3`)

- The canonical public benchmark page now lives at `/zig/benchmarks`, separate from the docs-book path.
- The March 30, 2026 published prepared-point medians are now `48,337 q/s` single, `561,055 q/s` pipeline, and `163,038 q/s` pool10 for qail-zig.
- Benchmark/release messaging now reflects the current three-way picture: qail-zig leads single-query throughput, while qail.rs currently leads the same published pipeline and pool10 slices.
- qail-zig docs, readme, and changelog references were bumped to `v0.6.3`.
